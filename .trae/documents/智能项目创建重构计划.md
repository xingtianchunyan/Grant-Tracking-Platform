# 重构计划：智能项目创建系统

本计划旨在通过后端临时存储和 AI 结构化提取，实现从 Discord 消息到前端页面的无缝、智能项目创建流程。

## 1. 数据库变更
*   **新建 `temp_messages` 表**：用于存储从 Discord 获取的原始消息内容。
    *   字段：`id` (UUID, PK), `content` (TEXT), `metadata` (JSONB, 存作者/链接等), `created_at` (TIMESTAMP), `expires_at` (TIMESTAMP).
    *   目的：解决 URL 长度限制问题，实现大文本传输。

## 2. 后端 API 开发
*   **`POST /api/discord/temp-message`**：
    *   接收 Discord Bot 发送的消息内容。
    *   存入 `temp_messages` 表。
    *   返回 `tempId` (UUID)。
*   **`GET /api/discord/temp-message/[id]`**：
    *   供前端调用，根据 `tempId` 获取原始消息内容。
*   **`POST /api/ai/extract-project-info`**：
    *   接收文本内容。
    *   调用 LLM (SiliconFlow API) 进行结构化提取。
    *   返回 JSON 格式的项目字段（Project Name, Description, Category, etc.）。

## 3. Discord Bot 升级 (`create-project.ts`)
*   **逻辑变更**：
    *   不再将内容放入 URL。
    *   调用 `POST /api/discord/temp-message` 存储内容。
    *   生成的按钮 URL 改为 `/admin/projects/new?tempId=UUID`。

## 4. 前端页面升级 (`app/admin/projects/new/page.tsx`)
*   **加载逻辑**：
    *   检查 URL 是否包含 `tempId`。
    *   若有，调用 `GET /api/discord/temp-message/[id]` 获取内容。
    *   获取内容后，自动调用 `POST /api/ai/extract-project-info`。
    *   收到 AI 结果后，自动填充表单字段（包括下拉菜单）。
*   **UI 交互**：
    *   增加 "AI Analyzing..." 加载状态。
    *   填充完成后显示 Toast 提示。

## 5. 执行步骤
1.  **数据库**：创建 SQL 迁移脚本并执行，建立 `temp_messages` 表。
2.  **后端**：实现 `temp-message` 的读写 API。
3.  **后端**：实现 `extract-project-info` API (集成 SiliconFlow)。
4.  **Bot**：修改 `create-project.ts` 对接新 API。
5.  **前端**：改造 `new/page.tsx` 对接新流程。
6.  **验证**：重启服务并测试完整流程。
